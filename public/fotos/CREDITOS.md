# Créditos de las fotos

Las fotos de esta carpeta vienen de [Pixabay](https://pixabay.com) y se usan bajo la [licencia de contenido de Pixabay](https://pixabay.com/service/license-summary/): uso gratuito, comercial incluido, sin atribución obligatoria. Aun así se listan sus fuentes.

Dirección de arte: **manos que trabajan**. Detalles de manos, objetos y luz cálida en vez de modelos posando: se ven verdaderas y coherentes entre sí. Una foto nueva debe seguir esa línea.

Se descargaron por la API de Pixabay (que no permite enlazarlas en caliente), se redimensionaron a WebP (máx. 1200 px, calidad 78, sin metadatos) y se sirven desde el propio sitio.
